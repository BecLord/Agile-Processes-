# Documentation

This folder is reserved for project-level documentation and planning notes.

## Current structure

- `README.md` in the repository root provides the main overview for the app.
- App source code is kept under the `app/` module.
- Gradle and Android project configuration remain at the repository root for standard project setup.

## Recommended conventions

- Keep user-facing product docs here.
- Add architecture or feature notes as the app grows.
- Keep implementation details in the codebase and reference them from this folder.
